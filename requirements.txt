# По умолчанию pip ставит с PyPI сборку с CUDA, даже когда видеокарты нет
# и в помине. Замеренный вес: сам torch 1.2 ГБ плюс пятнадцать пакетов
# nvidia-* (cublas, cudnn, nccl, ...) ещё на 3.2 ГБ, плюс triton — итого
# больше пяти гигабайт на ровном месте. В нашей модели 430 тысяч
# параметров, она считается на CPU за миллисекунды, GPU ей не нужен.
#
# Строка ниже добавляет официальный индекс PyTorch со сборками без CUDA.
# Версия оттуда помечена +cpu, а по правилам PEP 440 версия с локальным
# суффиксом старше такой же без него — поэтому pip выберет именно её.
# Выходит ~200 МБ вместо 5.2 ГБ.
#
# Проверить, что приехало: python -c "import torch; print(torch.__version__)"
#   2.x.y+cpu  — то, что нужно
#   2.x.y+cu130 — снова CUDA, индекс не подхватился
